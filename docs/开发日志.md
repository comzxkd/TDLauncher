## 一、主线：界面重构（用 oil-ui 技能）

流程：先定方向 → 挑风格 → 挑版式 → 逐轮细化。

1. **风格卡片**：生成 6 种风格（石墨信号 / 磷光仪 / 终端 / 霜面 / 纸面 / 墨刊），最终选定 **「终端」**（纯黑 + 磷绿、全等宽、直角）。
2. **版式方案**：按终端风格出 3 套真实可操作界面，「01 监视台 / 02 队列台 / 03 命令行」，最终选定 **「02 队列台」**（左队列 / 右详情的下载管理器）。
3. **多轮细化**：
   - 功能全保留；字号整体调大（13px → 15px）
   - 顶部改为**左链接 / 右参数**左右分栏，链接区加宽到约 1/4
   - 按钮风格统一；去掉 emoji，改纯文字
   - 队列缩窄、进度区加宽；清空按钮并入识别行
   - 三个操作按钮移到进度区右下角
4. **窗口缩放**：锁定 **16:9**，最小 **1280×720**，等比放大到全屏 2560×1440（整界面含文字一起缩放，基于 QGraphicsView）。

## 五、踩过的坑

1. **Gemini 改的 UI 撑爆窗口**：它把间距从 8/12 改成 12/16，960×720 装不下，底部按钮被挤出/点不动。解决：只取它的配色，保留原布局。
2. **`-t` / `-l` 语义一度理解错**：曾以为 `-l` 对单条链接无用。查 tdl 源码后确认：`-l` 并发的是「一个进程内所有来源的所有媒体条目」，只是当时 app 一条链接一个进程，喂不进去。
3. **多进程并行从原理上错误**：tdl 的 session 是 **bolt 数据库带独占锁**，第二个进程直接报 `Current database is used by another process`。实测复现后改为**串行执行**。
4. **批量并行模式（单进程 + 多 `-u` + `-l N`）**：技术上可启用 tdl 内置并发，但实测问题多——归档目录变成数字（用了 `DialogID` 模板）、漏文件、99% 卡住、活动计数不变，最终**整段移除**。
5. **评论区子任务卡 0%**：tdl 会打印 `... done!`，最初没有解析。解决：解析 `done!` 使子项完成即更新。
6. **测试污染配置**：测试脚本走 `_save_config`，会改写 `config.json`。解决：每次测试后手动还原。
7. **离屏渲染字体全变方块**：`QT_QPA_PLATFORM=offscreen` 不加载系统字体。解决：改用 `WA_DontShowOnScreen`（真实字体栈、不弹窗）。
8. **git push 反复 SSL 握手失败**：网络/代理波动。解决：循环重试。
9. **描述里没有文件名**：tdl 进度行只给「频道(id):消息ID」，**无法显示真实文件名**。逐文件列表只能显示下载描述符。
