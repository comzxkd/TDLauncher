# TDLauncher V0.2 — 评论区下载 + 归档 + 音频筛选

## 1. 评论区下载（核心增强）

### 1.1 tdl 底层命令流程

根据 tdl 官方手册，评论区媒体的正确下载流程是两步：

**第 1 步：导出评论区媒体列表**

```powershell
tdl chat export -c <频道标识> --reply <帖子ID> -o <json路径>
```

`-c` 可填：
- 公开频道用户名：`simisebaisi`
- 私有频道数字 ID：`1697797156`（注意：`t.me/c/xxx` 格式的链接中提取的数字 ID）

`--reply` 填帖子消息的数字 ID（不是评论 ID）。

**第 2 步：从导出的 JSON 批量下载**

```powershell
tdl dl -f <json路径> -d <下载目录>
```

### 1.2 完整交互流程

用户粘贴普通帖子链接（不是 `?comment=` 链接）：

```
https://t.me/simisebaisi/50063
```

勾选「下载评论区」后，程序自动按以下流程执行：

```
步骤 1: tdl dl -u <帖子链接> -d <目录> [过滤参数]
        ↓ 完成后
步骤 2: tdl chat export -c simisebaisi --reply 50063 -o <目录>/_comments_50063.json
        ↓ 完成后
步骤 3: tdl dl -f <目录>/_comments_50063.json -d <目录> [过滤参数]
        ↓ 完成后
步骤 4: 删除临时 JSON 文件
```

界面显示进度：

```
▶ [1/3] 下载帖子媒体...          ✅
▶ [2/3] 导出评论区媒体列表...    ✅
▶ [3/3] 下载评论区媒体...        ⏳ 67/110
```

### 1.3 链接类型兼容

| 用户粘贴的链接 | 评论区下载功能 |
|---|---|
| `t.me/channel/123`（公开帖子） | ✅ 可用，自动解析 channel 和 msg_id |
| `t.me/c/123456/789`（私有帖子） | ✅ 可用，chat_id 传给 `-c` |
| `t.me/channel/123?comment=456`（评论链接） | ❌ 不可用，提示「已是评论链接」 |
| `t.me/channel/123?thread=456`（话题链接） | 暂不支持（V0.2 先不做 topic） |

### 1.4 临时 JSON 文件管理

- 路径：`<下载目录>/_comments_<消息ID>.json`
- 下载完成后自动删除
- 如果 tdl 中途退出，保留文件以便排查

### 1.5 边界情况

| 情况 | 处理 |
|---|---|
| 帖子无媒体 | 跳过步骤 1，直接执行步骤 2、3 |
| 评论区为空 | tdl export 成功但空列表，提示「评论区无媒体」 |
| 评论区的媒体与帖子重复 | tdl 的 `--skip-same` 自动处理，默认启用 |
| 导出失败 | 帖子下载结果保留，评论区任务标记为失败 |
| 私有频道无权限 | tdl 返回错误，界面显示错误信息 |

## 2. 下载文件自动归档

### 2.1 归档策略

勾选「自动按帖子归档」后，下载目录下按消息 ID 建子文件夹：

```
D:/Downloads/
  50063/          ← 消息ID
    photo_1.jpg
    photo_2.jpg
    video_1.mp4
  51000/
    photo_1.jpg
```

命名规则：`{消息ID}`

- 只取帖子消息的数字 ID
- 不同频道内容类型一致，无需加频道名前缀
- 消息 ID 唯一、稳定、可直接追溯
- 子文件夹名短，便于路径操作

### 2.2 评论区下载时的归档

如果同时启用评论区下载和归档，帖子 + 评论区全部放在同一个消息 ID 子文件夹：

```
D:/Downloads/
  50063/              ← 帖子 + 评论区全部放一起
    photo_1.jpg         ← 帖子本身的媒体
    comment_photo_2.jpg ← 评论区的媒体
    comment_photo_3.jpg
```

帖子本身的下载命令：`-d D:/Downloads/50063`
评论区导出的 JSON 下载：`-d D:/Downloads/50063`

注意：帖子 + 评论区可能同名文件，`--skip-same` 可以跳过。

### 2.3 UI 展示

在下载设置区域：

```
☐ 自动按帖子归档
  归档格式：{消息ID}
  示例：50063
```

勾选后，实际下载目录 = 基础目录/消息ID。

## 3. 音频文件筛选

### 3.1 内容类型选项扩展

当前的内容类型：

```
(全部媒体) (仅图片) (仅视频) (自定义)
```

改为：

```
(全部媒体) (仅图片) (仅视频) (仅音频) (自定义)
```

### 3.2 tdl 参数映射

| UI 选项 | tdl 参数 |
|---|---|
| 全部媒体 | 不加 `-i` |
| 仅图片 | `-i jpg,png,gif,webp,jpeg` |
| 仅视频 | `-i mp4,mkv,mov,avi,webm,flv` |
| 仅音频 | `-i mp3,ogg,wav,flac,aac,m4a,wma` |
| 自定义 | `-i 用户输入` |

### 3.3 UI 修改

```
内容类型: (全部媒体) (仅图片) (仅视频) (仅音频) (自定义)
```

## 4. 配置文件变更

```json
{
  "download_dir": "D:/Downloads",
  "auto_subfolder": false,
  "download_comments": false,
  "content_type": "all",
  "custom_extensions": "",
  ...
}
```

新增字段：
- `auto_subfolder`：是否按帖子自动建子目录
- `download_comments`：是否下载评论区媒体
